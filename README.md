The ascend repository is meant to assist new Admins on some common configuration that exists out of the box with the ascend package.
If you're already confident in building flows, you'll find most of this repository are tablestakes configuration.
Most files are flows unless otherwise specified in the file names.

How to upload the zip files into your Salesforce org using Salesforce Inspector Reloaded is detailed in this blog post:
https://tiredsalesforceconsultant.wordpress.com/2026/10/01/downloading-and-uploading-metadata-with-salesforce-inspector-reloaded/
